# 安装与配置

## 1. 运行环境

- Windows 10/11 x64；NVIDIA GPU（监控与推理的显存数据来自 NVML，缺失时相关卡片显示 `—`）。
- 安装版自带 Python 运行时，无需另装 Python。
- 源码运行需 Python 3.11+ 与 `requirements.txt` 中的依赖。

## 2. 安装

1. 安装版：运行 `星虹智算-<版本>-setup-win64.exe`，默认安装到 `%LOCALAPPDATA%\Programs\XingHongPanel`。
2. 便携版：解压后直接运行 `XingHongPanel.exe`，配置与数据仍写入 `%LOCALAPPDATA%\XingHongPanel`。
3. 卸载只清除协议同意记录（`HKCU\Software\X.H\XingHongPanel\legal`），不删除偏好与 `%LOCALAPPDATA%\XingHongPanel` 下的数据；彻底清理请手动删除该目录。

源码运行：

```powershell
pip install -r requirements.txt
python xinghong_launcher.py
```

## 3. 首次配置

首次启动需同意用户协议与隐私说明。之后按需在「配置中心 → 进阶配置」填写本机路径；**所有配置项都可留空**，留空时界面仍可打开，只是对应功能按钮会提示未配置或不可用。

## 4. 本机路径配置项

写入 `%LOCALAPPDATA%\XingHongPanel\paths.json`（JSON 对象），或使用下表中的环境变量。环境变量优先级更高。

| 键 | 环境变量 | 含义 | 留空时行为 |
|---|---|---|---|
| `kvmem_bin` | `XH_KVMEM_BIN` | KVMem 引擎可执行文件 | 推理路线页启动失败并提示 |
| `models_dir` | `XH_MODELS_DIR` | 模型根目录（`root=models_dir` 的相对路径以此为基准） | 模型文件按相对路径解析，找不到会提示不存在 |
| `models_flash_dir` | `XH_MODELS_FLASH_DIR` | Flash 模型根目录（`root=models_flash`） | 同上，未配置时退回 `models_dir` |
| `lms_exe` | `XH_LMS_EXE` | LM Studio 命令行 `lms.exe` | LM Studio 路线不可用 |
| `comfy_root` | `XH_COMFY_ROOT` | ComfyUI 安装目录 | 「启动 ComfyUI」提示失败 |
| `comfy_store` | `XH_COMFY_STORE` | ComfyUI 存储根（其下有 `models/`、`input/`、`output/`） | 默认 `%LOCALAPPDATA%\XingHongPanel\ComfyUI_Storage` |
| `comfy_out` | `XH_COMFY_OUT` | 覆盖输出目录 | 默认 `<comfy_store>\output` |
| `comfy_input` | `XH_COMFY_INPUT` | 覆盖输入目录 | 默认 `<comfy_store>\input` |
| `kvmem_proxy` | `XH_KVMEM_PROXY` | 保活代理脚本 `.mjs` | 不启用保活代理，推理仍可用 |
| `node_exe` | `XH_NODE_EXE` | node 可执行文件 | 回退到 `PATH` 中的 `node.exe` |

示例 `paths.json`：

```json
{
  "kvmem_bin": "D:\\AI\\KVMem\\bin\\llama-kvmem-server.exe",
  "models_dir": "D:\\AI\\models",
  "models_flash_dir": "D:\\AI\\models-flash",
  "lms_exe": "C:\\Users\\<你>\\.lmstudio\\bin\\lms.exe",
  "comfy_root": "D:\\AI\\ComfyUI",
  "comfy_store": "D:\\AI\\ComfyUI_Storage",
  "kvmem_proxy": "D:\\AI\\KVMem\\kvmem-keepalive-proxy.mjs"
}
```

（JSON 中 Windows 路径的反斜杠需写成 `\\`。）

## 5. 模型档案

`backend/web-profiles.json` 保存推理档案。`model` 可以是绝对路径，也可以是相对路径；相对路径由 `root` 决定基准目录（`models_dir` 或 `models_flash`）。界面保存档案时只改上下文、KV 预算等参数，不会改写模型路径。

## 6. ComfyUI 模型路径

启动 ComfyUI 时，面板会根据 `comfy_store` 现场生成 `extra_model_paths.yaml`（放在 `%LOCALAPPDATA%\XingHongPanel\data`），`base_path` 指向 `<comfy_store>\models`；因此仓库里不需要、也不包含任何本机绝对路径。生成失败时退回随包的 `backend/comfy-paths.yaml`。

## 7. 升级与回退

- 覆盖安装即升级，`%LOCALAPPDATA%\XingHongPanel` 下的数据会保留。
- 回退：卸载后安装旧版本；协议同意记录会被清除，需要重新同意。
