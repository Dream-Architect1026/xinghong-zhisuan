# FAQ

## 面板能启动，但推理/生图按钮没反应？

先看「配置中心 → 进阶配置」里的本机路径是否为空。所有路径都可留空，留空时程序正常打开，但对应功能不可用；填入后立即生效，无需重启（个别项需重开页面）。

## 为什么窗口拖到最小尺寸时推理页列表最后一行被裁切？

窗口默认打开尺寸为 1000×731，`setMinimumSize` 为 980×640。在 980×640 下，左侧导航与卡片内边距已压缩到极限，推理页模型列表的最后一行会贴边、只露出一部分（不重叠、不产生横向滚动条，但纵向内容被裁切）。这是已知缺陷，原因与处理计划：

- 现象基线：980×640 实窗，推理页模型列表末尾行贴边裁切；1000×731 下完整显示。
- 计划处理：把模型列表改为内部滚动容器，并给最后一行补底部内边距；或把最小高度提高到 700。二者都需要同步验收其他六页，因此未在本版本擅自改动。
- 本仓库所有文档截图统一用默认尺寸 1000×731，不放大、不拼接；不以最小尺寸截图掩盖该缺陷。

## 端口被占用 / 启动失败：端口 1234 被抢绑？

KVMem 与 LM Studio 互斥占用 1234。面板启动前会检查端口并尝试释放；仍失败时提示「端口被占用」，请确认没有其他推理服务在运行，或在任务管理器结束残留的 `llama-kvmem-server.exe` / LM Studio 服务后重试。

## ComfyUI 启动失败，日志里说找不到模型路径配置？

面板在启动时会根据 `comfy_store` 生成模型路径配置；若生成失败会回退到随包 `backend/comfy-paths.yaml`（其 `base_path` 只是占位）。请检查 `%LOCALAPPDATA%\XingHongPanel\data` 是否可写，以及 `comfy_store` 是否指向真实存在的目录。

## 视频缩略图一直显示「加载中」？

超过大小阈值的视频不整段解码，会显示占位封面；这是为了避免大文件拖死缩略图线程。单个文件解码失败会自动重试有限次数，之后仍显示占位。

## 关闭窗口后程序还在运行？

关闭行为默认为「每次询问」，可选择最小化到托盘或直接退出。托盘图标右键可重新显示窗口或退出。这是常驻设计，不是后台自启：程序不会注册开机启动项或计划任务。

## 卸载后 API Key 还在吗？

API Key 使用 Windows DPAPI 按当前用户加密后存于注册表 `HKCU\Software\X.H\XingHongPanel`。卸载只删除协议同意记录（`legal/accepted`、`legal/accepted_at`），其余偏好与 `%LOCALAPPDATA%\XingHongPanel` 下的数据都会保留；需要彻底清除请手动删除该注册表键与数据目录。

## 为什么状态页的「C 盘剩余」显示的是别的盘？

磁盘健康按系统盘统计（`SystemDrive`）。若系统盘不是 C，卡片名仍显示 C 盘前缀的旧文案，数值取系统盘，属文案遗留，不影响判断。

## 支持多台机器共用一份配置吗？

`paths.json` 与 `web-profiles.json` 都可以随机器不同而不同；仓库内的默认值不含任何绝对路径，因此拷贝整个软件目录到另一台机器不会带上开发机的路径。
